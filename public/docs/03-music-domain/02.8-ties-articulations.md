# 02.8 — Ligaduras e Articulações

## Objetivo
Preparar o modelo para elementos que modificam a interpretação de eventos sem transformar esses elementos em novos tipos de nota.

## Ligaduras de valor
Uma ligadura de valor conecta duas ocorrências da mesma altura para formar uma duração musical contínua.

Ela deve ser representada como relação entre eventos:

```text
Nota A ──tie──> Nota B
```

Não devemos simplesmente transformar as duas notas em uma duração gigante, pois a divisão visual entre compassos e posições rítmicas precisa ser preservada.

Modelo conceitual:

```json
{
  "tie": {
    "start": true,
    "stop": false
  }
}
```

Para uma ligação completa entre eventos, o relacionamento também pode ser identificado por um `tieId`.

## Ligadura de expressão
A ligadura de expressão (slur) é diferente da ligadura de valor. Ela representa uma relação interpretativa/frasal entre eventos e não altera a duração matemática.

Portanto:

```text
Tie  → altera continuidade temporal
Slur → indica relação de interpretação/fraseado
```

## Articulações
O modelo deve permitir articulações associadas a eventos, inicialmente:
- staccato;
- accent;
- tenuto;
- marcato.

Estrutura conceitual:

```json
{
  "articulations": ["staccato", "accent"]
}
```

## Dinâmicas
Dinâmicas como `p`, `mf`, `f` e `ff` serão tratadas como elementos expressivos associados à posição temporal, e não como propriedade intrínseca da altura.

## Princípio arquitetural
Elementos de interpretação devem ser representados no Music Model e interpretados pelos sistemas de renderização e áudio.

```text
Music Model
   ├── Renderer → aparência
   └── Playback → comportamento sonoro
```

## Critérios de aceitação
- Tie e slur não podem ser confundidos.
- Tie deve preservar a divisão notacional entre eventos.
- Articulações podem coexistir em uma nota.
- Elementos expressivos não devem alterar o pitch armazenado.

## Decisões
- `MUSIC-022`: ligadura de valor é uma relação entre eventos.
- `MUSIC-023`: ligadura de valor e ligadura de expressão são conceitos distintos.
- `MUSIC-024`: articulação e expressão são metadados musicais interpretáveis por renderer/playback.
