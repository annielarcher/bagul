# 03 — Music Domain

O domínio musical é o núcleo semântico do produto.

```text
Partitura
└── Pauta
    └── Compasso
        └── Voz
            └── Evento Musical
                ├── Nota
                ├── Pausa
                └── Acorde
```

Eventos possuem posição temporal, duração e conteúdo musical. Posição, duração e andamento são conceitos distintos.
