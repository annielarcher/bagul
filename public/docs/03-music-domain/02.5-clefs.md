# 02.5 — Claves

## Objetivo
Definir como o Music Model representa claves e como o Music Engine relaciona altura musical, linha/espaço da pauta e representação gráfica.

## Princípio
A altura musical é independente da clave. A clave é uma instrução de interpretação gráfica da pauta.

```text
Pitch musical
    ↓
Sistema de pauta + clave
    ↓
posição gráfica
```

E, no sentido inverso:

```text
posição gráfica + clave
    ↓
Pitch musical
```

## Modelo

```json
{
  "type": "clef",
  "sign": "G",
  "line": 2,
  "octaveChange": 0
}
```

### Campos
- `sign`: `G`, `F` ou `C`.
- `line`: linha da pauta usada como referência.
- `octaveChange`: transposição gráfica da clave, quando aplicável.

## Claves iniciais
MVP:
- clave de Sol — `G2` na segunda linha;
- clave de Fá — `F3` na quarta linha;
- clave de Dó — estrutura preparada para posições como alto e tenor.

A clave deve ser um objeto do modelo, não um caractere desenhado pelo renderer.

## Posição na pauta
A posição vertical deve ser calculada a partir de uma referência diatônica, não apenas por número MIDI. Isso preserva a diferença entre, por exemplo, `C#` e `Db` na escrita.

O renderer recebe uma posição musical já interpretada pelo domínio e decide como desenhá-la.

## Clique na pauta
Ao clicar/tocar na pauta, o sistema deve:
1. determinar a pauta atingida;
2. identificar a clave vigente naquele ponto;
3. converter a coordenada vertical em posição diatônica;
4. determinar a altura correspondente;
5. aplicar contexto de acidente quando existir;
6. enviar o evento ao Music Engine.

O UI não deve calcular regras musicais finais.

## Mudança de clave
Uma partitura pode alterar a clave no decorrer do tempo. A clave vigente deve ser determinada pela posição temporal do evento.

```text
Compasso 1 → G
Compasso 2 → G
Compasso 3 → F
Compasso 4 → F
```

## Claves transpositoras
O modelo deve reservar `octaveChange` para claves como `G8va`, `G15ma`, `F8vb` etc., sem misturar essa informação com o pitch escrito.

## Critérios de aceitação
- O mesmo `Pitch` deve existir independentemente da clave.
- Trocar a clave deve alterar a posição gráfica, não o pitch armazenado.
- O clique vertical deve ser convertido de forma determinística.
- Mudanças de clave devem respeitar a posição temporal.
- O renderer não deve ser responsável por decidir a altura musical.

## Decisões
- `MUSIC-013`: clave pertence ao modelo musical e não ao renderer.
- `MUSIC-014`: pitch e representação gráfica são conceitos independentes.
- `MUSIC-015`: a conversão coordenada ↔ altura pertence ao domínio/serviço de notação.
