# 02.1 — Evento Musical

Um Evento Musical representa algo que ocorre no tempo musical e ocupa uma duração.

## Tipos iniciais
Nota, Pausa e Acorde.

## Duração
A duração é estruturada para suportar figuras pontuadas e futuras quiálteras.

```json
{
  "base": "quarter",
  "dots": 1,
  "tuplet": null
}
```

## Precisão
A implementação deve usar uma resolução inteira interna para posições e durações, evitando dependência de ponto flutuante.
