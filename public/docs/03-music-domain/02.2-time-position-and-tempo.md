# 02.2 — Posição Temporal e Andamento

- **Posição temporal:** quando o evento começa.
- **Duração:** quanto tempo o evento ocupa.
- **Andamento:** velocidade de execução.

Resolução interna inicial proposta:

- semínima = 480 ticks
- mínima = 960 ticks
- semibreve = 1920 ticks
- colcheia = 240 ticks
- semicolcheia = 120 ticks
- fusa = 60 ticks

Em 4/4, a capacidade é 1920 ticks. Ticks são uma régua interna de medição, não uma figura musical.
