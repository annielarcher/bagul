# 09 — Roadmap

## Estado atual
O projeto entrou no primeiro protótipo funcional.

### Protótipo 0.1 — Escrita essencial
- [x] React no frontend
- [x] Music Model estruturado
- [x] Music Engine isolado da UI
- [x] VexFlow como renderer
- [x] Pauta de clave de Sol em 4/4
- [x] Seleção persistente de duração
- [x] Inserção de notas por clique
- [x] Validação da capacidade do compasso
- [x] Desfazer da última nota
- [x] Salvamento local
- [ ] Reprodução de áudio

## Próximas fases
### 0.2 — Escrever e ouvir
Playback pelo Music Model, Web Audio API, Play/Stop, andamento e feedback visual.

### 0.3 — Editor musical básico
Pausas, acidentes, altura precisa, múltiplos compassos, mudanças de fórmula, seleção, exclusão e redo.

### 0.4 — Persistência e exportação
IndexedDB, MusicXML, SVG, PDF e MIDI.

### 0.5 — Experiência multiplataforma
Touch com snap musical, atalhos, ghost note, seleção contextual e responsividade refinada.

### 1.0 — Núcleo confiável
Polifonia, ligaduras, articulações, dinâmica, importação MusicXML, testes automatizados e migrações de schema.

### Futuro
Reconhecimento de escrita manual, MIDI de entrada, colaboração, contas e sincronização em nuvem.
