# 00 — Project Charter

## Nome
Bloco de Notas Musical

## Visão
Criar um bloco de notas musical digital que permita registrar uma ideia musical imediatamente, sem a complexidade de uma suíte profissional de notação.

## Proposta
**Abra → escreva → ouça → salve.**

## Princípios
1. A partitura já está pronta quando o usuário entra.
2. Escrever deve ser mais rápido que configurar.
3. O sistema entende regras musicais e ajuda o usuário.
4. Mouse, toque, teclado e futuras entradas convergem para o mesmo núcleo musical.
5. O modelo musical é a fonte de verdade; a renderização é uma representação.
6. A experiência nasce multiplataforma.
7. O produto prioriza captura rápida de ideias antes de buscar paridade com softwares profissionais.

## Estado atual
Fase: **fundação e documentação**.

Decisões que alterem esses princípios devem ser registradas em ADR.
