# Bloco de Notas Musical

Editor musical digital focado em capturar ideias rapidamente: **abra → escreva → ouça → salve**.

## Estrutura do projeto

```text
bloco-de-notas-musical/
├── README.md
├── public/
│   └── docs/
│       ├── 00-project-charter.md
│       ├── 01-product/
│       ├── 02-ux/
│       ├── 03-music-domain/
│       ├── 04-architecture/
│       ├── 05-data/
│       ├── 06-api/
│       ├── 07-engineering/
│       ├── 08-infrastructure/
│       └── 09-roadmap/
├── api/
├── lib/
├── migrations/
└── hatchable.toml
```

> No Hatchable, `public/docs/` é o espaço usado para manter os arquivos Markdown enquanto construímos a fundação do projeto. Quando migrarmos para um GitHub real, essa documentação poderá virar `docs/` na raiz sem alterar seu conteúdo.

## Documentação

Comece por `public/docs/00-project-charter.md` e depois avance pelas áreas numeradas.

## Princípio central

A ferramenta deve desaparecer e deixar a música aparecer.
